RAJSHAHI TOURS & TRAVELS - OFFLINE COUNTER MANAGER (DESKTOP 1.1.5)
===================================================================
This program runs on your own computer. Bookings and ticket records stay in a
local database; nothing is sent to the website or over the internet.


HOW TO OPEN IT
--------------
WINDOWS EXE: unzip the download and double-click RajshahiTours.exe.

SOURCE ZIP: install Python 3.10 or newer from https://www.python.org/downloads/
(tick "Add Python to PATH" during setup), then double-click app.py.

If the source app does not open on Linux, install Tkinter with:
  sudo apt install python3-tk


WHAT THE PROGRAM DOES
---------------------
* Overview: see this month's tour bookings, seats, due and upcoming trips.
* Tour bookings: enter a passenger name and phone, choose the tour date, select
  a tour and open seats on the map, then save. After a successful new or edited
  booking, the inputs clear and a fresh unique serial is shown. Select an existing
  row when you want to edit it.
* Tours & monthly reports: add tours with a short unique code and seat capacity;
  blank codes use initials from the tour name. New tour booking numbers include
  the code (for example, CBT-RTT-2026-0001). Export a selected travel month as PDF
  or CSV. Archive keeps booking history; **Delete tour + bookings** permanently
  erases the tour and its saved booking/payment records after confirmation.
* Bus tickets are separate from tour bookings and use their own ticket numbers.
  Issue offline tickets for a route and travel date; the 40-seat map checks
  occupancy for that route/date and stops duplicate seat sales.
* Booking and tour setup forms use larger, easier-to-read input boxes.
* The supplied company mark appears in the app window, task switcher and Windows
  executable icon. Print branded tour receipts and bus tickets; cancelled records
  release seats.
* Use File -> Backup database regularly to make a copy of every local record.

Tour receipts use the agency teal/orange mark. Owner Safayet Hossain and phone
01782250709 appear at the upper right. Update business details in Tools -> Settings.


WHERE YOUR RECORDS ARE KEPT
---------------------------
  Documents\Rajshahi Tours & Travels\bookings.db      <- bookings, tours, tickets
  Documents\Rajshahi Tours & Travels\settings.json    <- your settings
  Documents\Rajshahi Tours & Travels\Backups\         <- backups

On macOS / Linux the same folder is inside your home folder. Help -> About shows
the exact data folder. Keep a second backup somewhere safe.

IMPORTANT: do not delete bookings.db - it contains all tour bookings, the tour
catalogue and offline bus tickets.


WANT A DOUBLE-CLICKABLE WINDOWS EXE?
------------------------------------
Run build_windows.bat from a Windows computer. It makes
dist\RajshahiTours\RajshahiTours.exe. Copy that whole "RajshahiTours" folder
to the office computer and make a shortcut on the desktop.

On macOS / Linux run ./build_linux_mac.sh instead.
