RAJSHAHI TOURS & TRAVELS - OFFLINE COUNTER MANAGER (DESKTOP 1.2.5)
===================================================================
This program runs on your own computer. Bookings and ticket records stay in a
local database; nothing is sent to the website or over the internet.


HOW TO OPEN IT
--------------
WINDOWS EXE: unzip the download and double-click RajshahiTours.exe.

SOURCE ZIP: install Python 3.10 or newer from https://www.python.org/downloads/
(tick "Add Python to PATH" during setup). Open a terminal in the extracted
folder, run `python -m pip install -r requirements.txt`, then `python app.py`.
This installs HarfBuzz so Bangla text prints with correct letter shaping.

If the source app does not open on Linux, install Tkinter with:
  sudo apt install python3-tk


WHAT THE PROGRAM DOES
---------------------
* Overview: see this month's tour bookings, seats, due and upcoming trips.
* Tour bookings: enter a passenger name and phone, choose the tour date, select
  a tour and open seats on the map, then save. As with bus tickets, choose Male
  or Female in the seat map before clicking each seat (Male = blue, Female =
  pink); the booking list shows the markers (A-1 M, A-2 F). The printed memo
  carries a large faint logo watermark across the page. After a successful new or edited
  booking, the inputs clear and a fresh unique serial is shown. Select an existing
  row when you want to edit it.
* Tours & monthly reports: add tours with a short unique code and one or more
  buses. Every bus has a bus number and a type: 41 seats (rows A-J, five seats
  across the back row) or 45 seats (rows A-K, five across the back row). Use
  "+ Add bus" for multi-bus tours; each bus can be 41 or 45 independently. In
  the booking form choose the bus first, then the seats - every bus has its own
  seat map. Blank codes use initials from the tour name. New tour booking numbers include
  the code (for example, CBT-RTT-2026-0001). Export a selected travel month as PDF
  or CSV. Archive keeps booking history; **Delete tour + bookings** permanently
  erases the tour and its saved booking/payment records after confirmation.
* Corporate tour: a whole tour booked by a company. Choose or type the company
  name, the contact person, the tour date and the buses (bus number plus 41 or
  45 seats - no seat plan). Type the itinerary, package and conditions in the
  Details box; the printed memo continues onto extra pages when the details
  are long. Memos are numbered RTT-CORP-<year>-0001 and can be exported as CSV.
* Bus tickets are separate from tour bookings and use their own ticket numbers.
  Every route/date runs one 41-seat bus until you change it: in the "Bus &
  coach type" row pick 41 or 45 seats for that day's bus, or press "+ Bus" to
  run a second coach (each bus can be 41 or 45 independently). Tickets are
  sold per bus, so pick the bus first, then the passenger count, then the
  seats; assign the same number of open seats, and mark each
  Male (blue) or Female (pink). Fare is per passenger; one group ticket stores
  the contact and all passenger seats. Cancelled tickets release every seat.
* Fonts and input boxes across the app are larger and easier to read.
* The supplied company mark appears in the app window, task switcher and Windows
  executable icon. Tour booking memos are in Bangla and include booking terms;
  the office address is Vodra Mor, Rajshahi. Bus ticket receipts remain separate.
* Print branded tour receipts and bus tickets; cancelled records release seats.
* Memos and tickets open and print through a real PDF viewer (Foxit, Adobe
  Reader or SumatraPDF are found automatically; choose another under Tools ->
  Settings -> "PDF viewer program"). Do not print them from Microsoft Word:
  Word converts the page instead of drawing the embedded Bangla font.
* Use File -> Backup database regularly to make a copy of every local record.

Tour receipts use the agency teal/orange mark. Owner Md Safayat Hossain and phone
01782250709 appear at the upper right; the office numbers 01782250709 and
01744262302 are printed in the letterhead and footer. Update business details in Tools -> Settings.


WHERE YOUR RECORDS ARE KEPT
---------------------------
  Documents\Rajshahi Tours & Travels\bookings.db      <- bookings, tours, tickets
  Documents\Rajshahi Tours & Travels\settings.json    <- your settings
  Documents\Rajshahi Tours & Travels\Backups\         <- backups

On macOS / Linux the same folder is inside your home folder. Help -> About shows
the exact data folder. Keep a second backup somewhere safe.

IMPORTANT: do not delete bookings.db - it contains all tour bookings, the tour
catalogue and offline bus tickets.


WANT A DOUBLE-CLICKABLE WINDOWS EXE?
------------------------------------
Run build_windows.bat from a Windows computer. It makes
dist\RajshahiTours\RajshahiTours.exe. Copy that whole "RajshahiTours" folder
to the office computer and make a shortcut on the desktop.

On macOS / Linux run ./build_linux_mac.sh instead.
